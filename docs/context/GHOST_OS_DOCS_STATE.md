## 已解决问题
- 报价系统现在可以独立维护易损件模块，避免把易损件误加到服务包或主配置中。
- 新模块的数据库 schema、编辑器规范化、预览分组和金额明细已保持一致。
- 产品相关页面不再依赖分散的导航文本，导航标签与路径一致性更强。
- 共享 shell 渲染前会强制将 `/products` 导航标准化为 `300kW` 和 `1000kW` 两个入口。
- header 登录按钮的颜色、圆角、阴影和 hover 行为已通过共享层固定，减少页面级覆盖风险。

## 当前风险
- 新增易损件模块目前只在 G300 产品数据中预置；其他产品会在编辑器规范化时显示空模块，首次保存后才会持久化其 section 配置。
- 生产环境 FTP 仍依赖 `.vscode/sftp.json` 作为默认配置来源；`.env.ftp` 缺失不会阻断部署脚本，但不应将密码写入仓库。
- 站点里仍可能存在旧页面或历史副本引用旧的产品导航或登录逻辑，需要后续逐页巡检。
- 如果浏览器缓存了旧的共享脚本，短时间内可能仍看到旧样式，需要刷新或重载静态资源版本。
