01. 第一阶

物理能量转化 (废气 $\rightarrow$ 电力)

INPUT PARAMETERS:
$V_{gas}$ = 日均燃烧气量 ($m^3/\text{day}$)
$H_{gas}$ = 天然气热值常量 ($10\text{ kWh}/m^3$)
$\eta_{gen}$ = 发电机组综合转化效率 (39%)

气转电持续功率模型

$$P_{kW} = \frac{V_{gas} \times H_{gas} \times \eta_{gen}}{24}$$
  • ▶ 原始输入： 离网搁浅天然气/伴生气
  • ▶ 系统动作： 经由底层硬件 39% 极致热力转化
  • ▶ 输出结果： 稳定、连续的工业级电功率极大值 ($P_{kW}$)

02. 第二阶

算力降维映射 (电力 $\rightarrow$ 算力)

HARDWARE PARAMETERS:
$P_{kW}$ = 第一阶所得持续电功率
$E_{rig}$ = 单T算力功耗比
(水冷标准界定为 $0.03\text{ kW/TH}$)

电转总算力输出模型

$$H_{total} = \frac{P_{kW}}{E_{rig}}$$
  • ▶ 中间介质： 无法并网消纳的持续电力
  • ▶ 系统动作： 饱和式供电于标准化水冷算力单元
  • ▶ 输出结果： 物理电能 100% 映射为全球加密网络算力资产 ($H_{total}$)

03. 第三阶

金融资产变现 (算力 $\rightarrow$ 美元)

$R_{TH}$ = 全网日均每T产出 (BTC)
$P_{BTC}$ = 预言机实时美元定价 ($USD)
$C_{gas}$ = 搁浅气源成本 (恒定 $\$0$)

日化毛收益与年化矩阵

$$Rev_{daily} = (H_{total} \times R_{TH} \times P_{BTC}) - (V_{gas} \times C_{gas})$$
$$Rev_{annual} = Rev_{daily} \times 365$$
  • ▶ 底层逻辑： 零成本极值套利
  • ▶ 系统动作： 算力高位抛售，挂载全球最高共识流动性
  • ▶ 输出结果： 绝对的美元净利润 ($Gross Profit)

04. 最终阶

极速回本周期测算 (ROI)

静态回本月数估算模型

$$Payback\text{ (Months)} = \frac{CAPEX}{(Rev_{annual} / 12)}$$
  • ✖ 传统能源基建：5 - 8 年漫长回收期
  • ✔ GasGx 引擎：按固定单位千瓦 CAPEX 核算，实现月度极速静态回本
